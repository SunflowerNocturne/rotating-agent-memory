# Goal

Learn the core ideas of maximum likelihood estimation well enough to solve exam-style problems without rote memorization.

## Success Criteria

- Explain what likelihood means in plain language.
- Set up a likelihood function from a probability model.
- Convert likelihood to log-likelihood.
- Find the estimator and check whether the answer makes sense.
- Identify common traps such as support constraints and boundary solutions.

## Constraints

- Use first principles.
- Keep formulas connected to meaning.
- Preserve course terminology for exam writing.

## Persistence Rule

Before starting or resuming work, read both `goal.md` and `handoff.md`.

Update this file only when the learning goal, constraints, direction, success criteria, or "do not do" guidance changes.

Update `handoff.md` after each completed operation.
